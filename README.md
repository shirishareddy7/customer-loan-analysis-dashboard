# Customer Loan Analysis – Interactive Dashboard (Excel-Based Data Analysis)
## Project Objective
The objective of this project is to analyze customer loan data from 2007–2011 and create an interactive dashboard to understand loan distribution, customer behavior, and repayment trends. This helps in identifying risk patterns and improving lending decisions.
